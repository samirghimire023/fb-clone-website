# fb-clone-website
# 📘 FB Clone Website

A simple **Facebook Clone Website** built using **HTML, CSS, and JavaScript** as part of a Git and GitHub learning project.

This project was created during our Git tutorial to practice version control, repository management, commits, branches, and collaboration while building a real-world frontend project.

---

## 📖 About the Project

The **FB Clone Website** is a frontend recreation of Facebook's user interface. The goal of this project was not to copy every feature of Facebook but to understand how a modern social media website is structured using basic web technologies.

While learning Git and GitHub, we created this project to practice:

- Creating repositories
- Tracking project changes with Git
- Making commits
- Working with branches
- Merging branches
- Pushing code to GitHub
- Managing project versions

This repository serves as both a web development project and a Git practice project.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Learn Git and GitHub from scratch.
- Practice frontend development.
- Understand website layouts.
- Improve HTML and CSS skills.
- Learn responsive web design.
- Gain experience working with project folders.
- Build confidence using Git commands.

```bash

```

Go inside the project.

```bash

```

```bash

```

```bash

```

No additional installation is required.
